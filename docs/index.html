Real-time PC hardware stats streamed to an Android dashboard over local Wi-Fi.

DOWNLOADS→ VIEW ON GITHUB[Xeakaes/PcHWmonitor]

Sensor Coverage

CPU[01]

Temperature, usage, clock speed, power, per-core load

GPU / iGPU[02]

Hotspot, VRAM, core & mem clock, watt

RAM[03]

Used / total GB, usage %, MHz

Disk & Network[04]

Read/write MB/s, download & upload

Fan[05]

Labeled fan RPM readings

FPS[06]

Current, average, and 1% low via PresentMon

Features

01

Live charts & 1-hour history

30s / 60s / 300s window selection, one hour of history stored in a Room database.

02

2×2 landscape grid

All cards on one screen, compact and scroll-free.

03

14 languages supported

Selectable from the Settings tab, with light/dark theme and custom logo support.

04

Zero-install Windows EXE

Single file with an embedded LibreHardwareMonitorLib.dll; --simulate mode when no hardware is available.

System Architecture

01 →

PcHwMonitor.exe :8765

In-process reads via an embedded LibreHardwareMonitor library; disk/network via psutil, FPS via PresentMon64.

02 →

ws://<pc-ip>:8765/ws

Sends a welcome message on connect, then a status message once per second.

03 →

Android · Jetpack Compose

The phone, on the same Wi-Fi network, only talks to the server — it never touches the hardware directly.

Quickstart

01/

Run the EXE

Open dist\PcHwMonitor.exe and accept the UAC prompt — admin rights are required for CPU temperature.

02/

Connect your phone

In the app's Settings tab, enter the PC's Wi-Fi IP (e.g. 192.168.1.50) and port 8765, then tap Save.

03/

Manage from the tray

The server sits in the system tray next to the clock; right-click → Exit to stop it.
