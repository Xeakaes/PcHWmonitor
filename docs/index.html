Features

Full system telemetry on one screen

A Jetpack Compose Android app paired with a single-file Windows server — no setup headaches.

CPU / GPU / iGPU / RAM

Temperature, usage, clock speed, power draw, VRAM/RAM, and per-core loads — all card-based.

Disk, network, fans, FPS

Disk usage and throughput, network traffic, fan RPM, and real-time game FPS via embedded PresentMon.

Live charts and history

30 / 60 / 300-second chart windows, plus a 1-hour history stored in Room DB that cleans up automatically.

Compact landscape mode

All cards fit a single scroll-free 2×2 grid in landscape — turns your phone into a desk monitor.

Zero-install server

A single-file Windows EXE with an embedded LibreHardwareMonitor DLL for in-process reading.

14 languages, light/dark theme

Pick your language and theme in Settings, add a custom logo, and it's fully open source under AGPL-3.0.

v1.4 · latest release

Setup: server + app

Run the EXE on your Windows PC, install the APK on your phone, then enter the PC's IP address and port 8765 in Settings — that's it.
